## 검색엔진 기술 체크리스트
1. `https://sangjin-fa.com` 대표 도메인, www 및 HTTP/HTTPS 리디렉션, DNS 인증서 정상 여부 확인.
2. Google Search Console의 도메인 인증 및 sitemap 제출: `https://sangjin-fa.com/sitemap.xml`.
3. 네이버 서치어드바이저의 사이트 인증, 사이트맵 제출, 로봇 수집 점검.
4. 페이지별 고유 title, description, canonical, Open Graph 및 실제 콘텐츠 H1 확인.
5. Organization 및 사업별 Service 구조화 데이터 유효성 검사 (Google Rich Results Test 및 Schema Markup Validator).
6. Pages 정적 빌드 산출물에서 robots.txt와 sitemap.xml 정상 생성 확인.
7. 실제 이미지와 프로젝트 설명의 정확성 검토. 실적·업무 범위는 사실에 기반해 유지.
8. 모바일 레이아웃 및 문의 기능 회귀 점검, Core Web Vitals 개선 (이미지 용량·CLS·LCP).

## 운영 주의
- Google은 meta keywords 태그를 검색 순위 신호로 사용하지 않습니다. 페이지 본문, 명확한 제목, 내부 링크, 전문성 있는 실적 설명이 더 중요합니다.
- 검색 색인과 상위 노출은 보장되지 않으며 검색엔진의 재수집과 평가가 필요합니다.
- 이번 변경은 홈페이지 코드 개편이며, 라이브 DNS·검색엔진 등록 작업 자체를 대체하지 않습니다.
