# 지엠상진 네이버·구글 검색 등록

## 웹사이트 기본 주소
- 대표: https://sangjin-fa.com
- robots: https://sangjin-fa.com/robots.txt
- sitemap: https://sangjin-fa.com/sitemap.xml
- www 도메인이 연결되어 있다면 대표 주소로 리디렉션되는지 확인

## Google Search Console
1. https://search.google.com/search-console/ 열기
2. 도메인 `sangjin-fa.com` 속성 등록, 발급된 DNS TXT 레코드로 소유권 인증
3. Sitemaps 메뉴에서 `https://sangjin-fa.com/sitemap.xml` 제출
4. URL 검사에서 홈, /automation, /business, /dacro, /references 수집 및 색인 상태 확인
5. 404, 중복 canonical, 서버 응답, 수집 차단 오류 정기 점검

## 네이버 서치어드바이저
1. https://searchadvisor.naver.com/ 에 사이트 등록
2. 소유확인용 실제 HTML 파일 또는 실제 메타태그 값을 등록
3. 요청 > 사이트맵 제출에서 `https://sangjin-fa.com/sitemap.xml` 입력
4. 사이트 간단 체크 및 수집 요청 확인

## 운영
- 실제 시공 사진·공정 설명·검사 또는 전기제어 사양·고객 질문을 분야별로 계속 보강
- 검색량만 노린 무의미한 키워드 반복, 숨김 글자, 허위 프로젝트는 피함
- 네이버와 구글 모두 meta keywords 자체보다 웹문서 본문 품질·정확한 제목·실제 콘텐츠·색인 상태가 중요
- 검색 노출 순위와 색인은 보장되지 않음
